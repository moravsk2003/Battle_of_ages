# Відомі проблеми

Усе, що ще не виправлено або не вирішено. Стан на 2026-11-03, остання збірка Windows **0.2.11**.
Коли пункт виправлено й перевірено, його звідси видаляють, а зміну описують у `GAME_DESIGN.md` §18.3.1. Номери не змінюються, тож пропуски в них означають виправлені пункти.

**Стани:**
- **Відкрито:** ще не виправлено.
- **Чекає рішення:** технічно зрозуміло, потрібен вибір автора.
- **Чекає даних:** не відтворюється, потрібне відео чи сейв від гравця.
