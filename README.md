# ⚔️ Battle of Ages

Фентезійна пісочниця на Unity 6 (URP): відкритий світ від першої особи, розбудова поселення й масові бої на мапі,
королівства ботів, що ростуть і воюють самі, і гра до кількох гравців за IP. Умови перемоги немає: епохи, артефакти,
суперники й зростання королівства.

Остання збірка — **Windows 0.3.6** (IL2CPP); macOS — 0.1.2 (застаріла, див. `docs/KNOWN_ISSUES.md`).

## Що є в грі

- **Герой від першої особи:** рубка дерев, збір руди, бій мечем, луком чи посохом, класи й уміння, артефакти,
  рівні й очки характеристик, спадкоємець після смерті.
- **Мапа (M):** виділення й накази юнітам, розмітка зон (житло, поля, ліс, ремесла, шахти, торгівля), споруди, стіни з
  воротами й сходами, ратуша I–V, тривога, ринок, верстак із чергою крафту.
- **Ранги людей:** людина → воїн → лицар → генерал, один тип юніта і для роботи, і для бою; спорядження в 6 слотах
  (зброя, щит, шолом, броня, рукавиці, чоботи) рівнів I–V.
- **Світ:** скінченний, із сіду (від 4 до 24 км, за замовчуванням 8; до 50 королівств), біоми, озера, табори бандитів, звірі. Справжні королівства ботів поруч,
  далекі — даними: набіги, армії, бої цифрами, падіння королів (абстрактний шар).
- **Мережа:** лобі перед стартом, вхід за IP, кожен гравець рахує своє, удари й убивства між гравцями, спільні дерева,
  табори, тварини, зони й час, пауза для всіх (F6), бот на місці гравця, що вийшов.

## Керування (за замовчуванням, перепризначається в налаштуваннях)

| Клавіша | Дія |
|---|---|
| `W A S D`, миша | рух і погляд (від першої особи), камера (мапа) |
| `ЛКМ` | удар / постріл; на мапі — виділення |
| `ПКМ` | на мапі — наказ: іти, працювати, бити |
| `M` | перша особа ⟷ мапа |
| `E` / `F` | збір і взаємодія / рубання дерев |
| `I`, `C`, `H` | інвентар, спорядження, герой |
| `B`, `K` | будівництво, розподіл робіт |
| `Q`, `R` | уміння класу |
| `1`, `2` | артефакти: повне зцілення, блискавка |
| `T` | тривога (усі на захист) |
| `N` | мапа світу |
| `V` | автоходьба |
| `Tab` (утримувати) | хто в грі |
| `G`, `X`, `L`, `.`, `Space` | на мапі: усі бійці, стій, камера до обраних, робітник без діла, до місця нападу |
| `F1` | довідка |
| `F3` | лічильник кадрів |
| `F5` / `F9` | швидке збереження / завантаження |
| `F6` | пауза для всіх у мережевій грі |
| `F8` | редактор тестувальника (лише одиночна гра) |
| `Esc` | меню паузи / закрити вікно |

## Запуск

- **Unity 6000.3.6f1** (Unity Hub). Відкрити `Assets/Scenes/MainMenu.unity` і натиснути Play (або одразу
  `SampleScene` — світ без меню).
- **Тести:** `tools\run_tests.ps1` — короткий прогін (усі EditMode і PlayMode без `[Category("Slow")]`, ~2 хв);
  `-Full` — усе; `-Filter Назва` — окремі. Лише один batch Unity одночасно, проєкт у редакторі закритий.
- **Збірка Windows:** `-executeMethod BattleOfAges.EditorTools.BuildGameTool.BuildWindows` (IL2CPP, потрібні модуль
  Windows IL2CPP і C++ build tools); тека — `BUILD_DIR` або `Builds/Windows`.
